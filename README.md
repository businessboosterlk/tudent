# Tudent · design preview

Static build of the Tudent entry screens, published so the design can be held
on a real phone. **Sign-in is switched off** and this build contains no
database client, no keys and no network calls of any kind.

Screens: the cover, the page turn, the teacher and student sign-in pages, and
the join arrival.

Source lives privately in `~/bb-systems/batch` (the internal
directory and package names stay as they are until the name is final). Nothing here is the product.
